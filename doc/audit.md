## 1. ПАМЯТЬ И РЕСУРСЫ

Новый код держит только списки путей — O(F) имён, FD не открывает, темпов не создаёт,
потоков не плодит (работает до пулов). Лимиты архивов/пикселей не затронуты.
`os.walk(..., followlinks=False)` везде, включая `_walk_books` и `_glob_walk`.

| Блок кода | Тип (Крит/Warning/Opt) | Описание | Как исправить |
|---|---|---|---|
| `_glob_walk` × N масок | Warning | Полный обход cwd **на каждую** маску: O(k·дерево). При `-r '*.a' '*.b' …` дерево читается k раз | Один общий обход: собрать маски/имена заранее, за один `os.walk` разложить хиты по запросам. Заодно −30…40 строк |
| `_glob_direct` (абсолютные маски) | Opt | Маска вне cwd (`/etc/*.fb2.zip`) возвращает внешние пути — только листинг, чтение тел нет; ок | Не чинить; упомянуто для полноты |
| `_expand_sources`: дедуп по `abspath` только при `-r` | Opt | Один и тот же файл, переданный дважды без `-r`, обработается дважды (как раньше); с `-r` — один раз | Оставить (историческое поведение не-рекурсивного пути) |

## 2. БЕЗОПАСНОСТЬ

Инъекций нет: `glob`/`fnmatch` — только листинг, `shell=True` отсутствует (как раньше),
подстановки выполняются над путями, команды не строятся. Терминальные инъекции через
имена закрыты: новые подписи идут через `_disp`, а ошибки батча теперь тоже
санитизируются (`_disp(_err_label(...))`) — **улучшение** относительно прошлого
`f"[error] {path}"`. Симлинки-файлы по-прежнему скипаются в `_optimize_one`,
включая найденные обходом.

| Блок кода | Тип (Крит/Warning/Opt) | Описание | Как исправить |
|---|---|---|---|
| `_glob_direct` → `_walk_books(m)` | Opt | Совпавшая с маской **директория-симлинк** обходится (`os.walk` на корне-ссылке листит её саму) — та же семантика, что у явного `fb2opt -r linkdir` | Не чинить без Architect (менять семантику `-r` ради маски нельзя); максимум — документировать |
| `_find_exact_recursive` находит не-книги | Warning | Точное имя `other.txt` из подпапки находится, затем падает с `need .fb2 or .zip` (шум вместо тишины dir-обхода, который берёт только `.fb2.zip`) | Либо фильтровать до книг (тихо скипать чужое), либо оставить явную ошибку — решить с Architect и покрыть тестом; сейчас поведение «найти и честно упасть» приемлемо |
| Маска без `-r` | Warning | `fb2opt '*.fb2.zip'` (кавычки, без `-r`) → голое `file not found`, хотя пользователь явно имел в виду маску | Подсказка: если без `-r` аргумент содержит magic и не существует — `file not found (did you mean -r?)`. 3 строки + тест |

## Проверка новой логики (что именно ревьюилось)

1. **Кроссовер gif/bmp→PNG.** Причина проигрыша найдена верно (RGB-энкод палитры).
Фикс mode-native + сортировка по packed + существующие гейты (`_pixels_equal`,
packed-строже, ect) — инвариант pixel-identity сохранён архитектурно, а не честным
словом. Замер на книге `0/`: GIF 1816 Б → PNG 969 Б (= эталонная конвертация),
книга −736 Б. Lossless-корпус 16 книг vs HEAD: 15/16 побайтово, 1 файл −18 Б
(только MIME-орфография, байты картинок идентичны — сверено md5). Keep-исключения
(анимация/прозрачность/EXIF/мультистраницы) корректны и покрыты.
2. **Гейт bilevel (дыра v19 §4).** Проверено на точной синтетике аудита (1000×1400,
вклейка 140×105): тёмная/светлая/серая — все три отклоняются до метрики; сквозной
CLI-прогон с реальным ffmpeg: было 1 уровень (фото уничтожено), стало 127 (цело).
Серая бумага (плотная/разреженная, 180/200) — 0.0, идёт в 1-bit (ложных срабатываний
нет, замерено). Ход с полосой вокруг фактического Otsu вместо 128 — правильный и
единственно корректный (гейт обязан охранять применяемый порог). Остаток честно
записан в README (суб-0.5% вклейки, туман на всю страницу — слепота SSIM по построению).
3. **EXIF-ориентация.** Разбор подтверждён независимо: `ect -strip` ронял тег без
поворота пикселей. Фикс: jpegtran-транспонирование (без перекодирования) с тройной
проверкой; отдельно пойман и подтверждён замерами факт, что `jpegtran` на размерах
вне iMCU-сетки **молча (rc=0) портит картинку** — тройная проверка это ловит
(tolerance 232 > 16 → keep). Таблицы прямого/обратного отображения верны (самодвой-
ственность 2/3/4/5/7, пара 6↔8), допуск 16 при замере 3 — с запасом 5×, задокументирован.
Остаток: oriented other/TIFF под --lossy (Warning выше).
4. **MIME-канонизация.** Rewritten-путь и keep-путь (только существующий атрибут,
добавления нет) — корректны; `_set_content_type` идемпотентен (проверено: каноника
возвращается без изменений, churn нулевой). Тест `test_kept_gif_tag_untouched`
фиксирует, что GIF-кипы не переписываются.
5. **bench.py + C901-гейт.** bench: копии в tmp (оригиналы не трогает), `timeout=3600`,
без shell, детерминизм доказан (два прогона — одни md5). Гейт: `pyproject` max=23 =
текущий максимум, CI-шаг не-изолирован (читает конфиг), F/B/UP-гейт нетронут.
